# Insurance-Cost-Analysis-Prediction-with-Python.-Beginner-

Exploratory data analysis and multiple linear regression to study how
age, BMI and smoking status relate to medical insurance charges.

## Tools
Python, pandas, matplotlib/seaborn, scikit-learn

## Key findings
- Smokers have significantly higher medical charges
- Charges tend to increase with age
- Model performance: R² ≈ 0.78, MAE ≈ $4,260

## Limitations
The model uses only three variables, and results show associations,
not causation.

## Files
- `Insurance_Project.ipynb`: full analysis and model
- `insurance.csv`: dataset
